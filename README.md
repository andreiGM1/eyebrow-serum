# BrowLash™ — Ser Natural pentru Creșterea Sprâncenelor

Landing page de conversie mare pentru brandul cosmetic BrowLash, cu selecție dinamică a pachetelor de tratament (1 flacon, 2 flacoane bestseller cu reducere, 3 flacoane), calcul automat de livrare gratuită și formular de checkout rapid fără cont.

## Cum rulezi proiectul
- **Vizualizare Imediată:** Fă dublu-click pe `index.html` în browser.
- **Lansare Online:** Încarcă fișierele (`index.html`, `styles.css`, `app.js`) pe Cloudflare Pages sau Vercel.
- **Next.js:** Fișierul `page.tsx` este pregătit pentru utilizare în Next.js.
